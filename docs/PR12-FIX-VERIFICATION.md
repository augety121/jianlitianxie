## 实际故障和修复

1. **确认窗口在首次加载时失效。** 安装回归及临时测试副本的事件追踪确认：`onUpdated` 首次 loading 没有 URL 信息，原实现直接删除新票据。现在初次 loading 只保持“待绑定”，不授予数据访问；读取必须证明准确 URL（含票据）、tab、首个活动 document。之后的 loading、导航、关闭仍取消，超时与已消费票据仍拒绝。没有加入 tabs / webNavigation 权限或放宽 CSP。
2. **零匹配详情折叠后无法补选。** 已批准设计为默认收起；修复保留有效空计划的补选能力，用户展开后可正常打开单字段核对。已消费计划不重新开放补选。
3. **重启后常驻入口丢失。** 本机真实重启时观察到偏好仍为开启、权限仍在，但注册脚本列表为空。启动恢复仅依据已保存的明确 opt-in 和 Chrome 当前同来源权限；不新增授权，不扫描无关标签页，不自动写值。关闭设置不会被恢复流程重新启用；拒绝通配来源。
4. **回归测试仍使用旧协议/旧产品决策。** 单击 UI 模拟接口改为实际 `page-local-run` 协议；仍使用真实引擎并核对实际输入。空白多记录先断言未选，再明确选择记录、验证每个预期值。折叠详情先断言收起，再实际鼠标展开与补填。没有删除失败用例。
5. **历史版本常量误报。** 安装日志的版本断言与被安装清单一致，仍检查引擎与产品版本，不将 0.11.0 错判为必须等于 0.10.4。

## 新增反例
