# 0.15.0 资料恢复与回填：实施和验收记录

2026-10-02。基于 main 已合并的 PR #17 实施，构建标识 `recovery-20261002.1`。这是可升级测试的候选版；真实 Moka 的完整清空、回填和恢复未通过验收，不能宣传所有浏览器全流程可用。

## 解决的问题

0.14 用户日志中，清空后的五域新增目标都是零，姓名被相邻必填错误干扰；5 个普通字段写入成功不代表经历恢复。修复了标签清理后不继续回退的路径，必填标志限定到对应字段，避免相邻红星污染。Moka 独立年月日历支持真实月精度和有限翻年，遇到异常年份停止。

统一五域记录目录，语言参与学习和恢复。旧项目片段保留原文和来源，差异必须核对；修改前保留版本快照。每张采集卡片共用一次经历名称核对。空库可以只读生成草稿，确认前不落库、不开放写入。资料页支持选择本次记录，未选记录仍在库中；自动按顺序绑定仅限本次授权创建的整域空卡片，不能对已有歧义卡片猜顺序。

恢复后可“保存并继续填写”。任务回执区分执行前计划、执行后摘要与只读重扫；已有未核实值不计为通过。UI 打开必须有可信扩展页握手，创建 API 返回 ID 只表示请求已受理；拒绝、超时分别记录并撤销票据。不会为解除宿主限制开放 Shadow DOM、完整资料或额外权限。

日志 schema 4 记录 operation/task、当前版本、资料质量计数、所选/可用记录数、学习前后计数及 UI 打开状态。支持本次任务导出和用户声明环境；旧日志未知身份不补造。不包含个人值、原标签、URL 或原始异常。

## 实机与私有恢复状态

用户指定工作目录保留完整源码。个人原稿、截图、原始诊断及私有报告在仓库外，不进入公开 PR 或 ZIP。已盘点两份授权原稿；其中一份全部为未确认草稿，不能直接成为可填写事实。MCP 档案也不能冒充 Edge 当前 45 条库。

旧页面备份有 23 个 `<redacted>`，已经从候选资料中排除；私有核对草稿只有 44 条、均未确认，18 个卡片目标存在未知身份，不是完整可导入恢复包。真实恢复演练没有执行，恢复差异不能写为零。

只读检查时曾误触 Edge 日期菜单产生一项日期，已立即通过该控件的清除按钮恢复为空，未提交；不把这次人工操作算插件通过。后续维持用户当前表单，不在备份不完整时清空。

## 升级与保留资料

1. 在当前浏览器扩展资料页使用“导出全部版本”，保留原明文备份在本机。跨浏览器资料不会因扩展 ID 相同自动同步。
2. 在原安装目录更新完整 `extension` 内容并重新加载，保留 vendor。不要卸载、清空扩展存储或换一个新 ID 后误认为资料丢失。完整源码包包含 `extension`、源码、测试、文档和许可。
3. 关闭旧管理页；从申请页工具栏重新打开，核对面板为 `0.15.0`。若原安装目录不是本项目 `extension`，先确认路径后更新那个目录，不能以代码目录已升级推断浏览器已升级。
4. 先核对记录选择和旧资料恢复。点击“保存并继续填写”后观察五域可用数量；缺真实来源的记录一次汇总，不反复重传全部简历。
5. 已有完整可信资料、表单备份及恢复条件后再做实机回填。附件与预览提交保持人工；回读通过不代表网站已保存。

IAB 若仍提示 Owl 阻断，只记录宿主限制并保留表单。需要正式支持的扩展管理操作或用户手动重新加载；不能用脚本注入、代理管理页或原始调试协议绕过。
