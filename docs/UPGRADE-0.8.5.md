# 0.8.5 本地升级说明

## 开始使用

1. 已经用本仓库 `extension` 目录安装过：在浏览器扩展管理页点击该扩展的“重新加载”。保持原安装目录和原扩展，不卸载或清空存储。
2. 首次使用：解压扩展包，在 Chrome/Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `extension` 文件夹。
3. 进入“我的资料”，导入本地 JSON，展开并核对长短文。既有资料的更新默认不选，需勾选希望替换的更新项，再保存。
4. 打开招聘申请页，点工具栏图标和“填写简历”。普通且唯一匹配的空白项可直接填写；多段教育/项目无法唯一确定时，进入核对页指定经历。
5. 网页需要新增一段、展开折叠或切换下一页时，先操作网页再重新扫描。最终提交由本人完成。

## 长短文如何工作

每条叙述事实的 `value` 是原文，`textVariants` 是同一事实的备选版本，最多5份。姓名、证件、成绩、日期、薪资等不能设置文字备选。

```json
{
  "schemaVersion": 1,
  "facts": [{
    "id": "demo-project-description",
    "label": "项目描述",
    "section": "项目经历",
    "entity": "演示项目",
    "value": "这里填写完整项目正文。",
    "textVariants": [{"name": "短版", "value": "这里填写同一项目的简要正文。"}],
    "source": "本人核对",
    "confirmed": true
  }]
}
```

先完成分区、经历、来源和冲突检查，再从同一条事实中挑选能完整放进 `maxlength` 的最长版本。不会因为另一个项目更短就拿来填；两条冲突事实仍需选择。网页没提供可读取上限时使用最长版本，不猜测隐藏的业务限制。所有版本都超限则说明原因并留空，不截断或自动生成。修改项目事实后也要检查短版是否需要同步更新。

导入和本地编辑均展示各版本。UI与JSON都能维护，仍兼容不含 `textVariants` 的旧JSON。导入中增加短版视为资料更新，不再当作完全重复忽略。

## 本轮修复

- 例子占位符曾先于标准 `autocomplete`，导致邮箱等字段识别错误；现在正式标签/ARIA优先，其次明确 `data-label`，标准自动填充标识优先于占位示例。
- 共同行容器内多个输入框不再复用首个字段标签。支持 ARIA 标识之间的换行与制表符；密码/验证码标识不区分大小写。
- 英文 Name / Description 只在明确分区中解释；区分GPA和平均分、项目职责和项目成果。明确的“500字内”等尾注不再阻断标签匹配。
- 未填原因分为正文超限、选项不匹配、数字格式不符、日期精度不足等。面议不转成0或虚构薪资。
- 接回此前缺失的加密库方案保存、版本校验、备份保留及工作台可信复制路由。方案并发修改沿用原修订号防护，删除资料会清理方案引用。

## 开源参考

阅读了 [TshyGO/resume-form-assistant-plugin](https://github.com/TshyGO/resume-form-assistant-plugin) 及用户提供ZIP中的 `content.js` 标签识别和 `form-agent.js` 新增经历规划逻辑。该项目采用MIT许可。此次借鉴的是“字段识别→计划→执行→回读”和明确限定新增记录的思路，没有复制其源码，没有引入桌面服务、API Key或云端简历解析依赖。

参考代码会向祖先/兄弟节点搜索短文字，本项目保留较严格的所属标签判断，防止同一行错填相邻输入框。自动新增任意网站的经历行未宣称完成；现有特定子表支持保持原样，通用页面仍需本人添加后重扫。

## 验证与限制

- Node全套自动测试和发行检查结果见 `test-results/upgrade-20260929.txt`、`test-results/release-20260929.txt`。
- 新增测试覆盖长度边界、多项目与冲突、不同站点来源、导入复核、错误选项、面议数字框、英文分区标签、占位符与ARIA识别。
- 本轮内置浏览器访问本机验证页被拦截，原因是无法核验保存的浏览器权限。没有绕过拦截，没有运行替代浏览器获取同一页面。`tests/upgrade-demo.html` 已保存，供权限恢复后继续页面验收。
- 不能将函数/计划测试等同于已安装MV3测试，更不能称所有ATS网站均可用。跨域iframe、封闭Shadow DOM、虚拟滚动下拉、复杂联动、隐藏步骤仍可能需要手动处理。
- 版本是本地候选版，尚未推送GitHub。源目录有此前未提交工作，本次保留这些内容。包不含真实个人资料、Cookie、配对码或密钥；免口令资料仍只存本浏览器且未加密。

Jev仅审阅匿名的“同一事实按长度选择已核实版本”设计，判为适用；人工仍执行来源隔离、冲突保留与测试核对。没有发送个人资料或非公开项目正文，判断不是浏览器测试结果。
