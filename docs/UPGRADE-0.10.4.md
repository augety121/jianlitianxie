# 0.10.4：资料恢复、项目解析与实际填写回归

本版基于0.10.3，修复的是资料解析、经历匹配、范围日期以及结果诊断，不是重做一个填写按钮。

## 升级与最短操作

备份原安装目录和资料，不卸载、不清空浏览器存储。将升级包的 extension 内容覆盖到原 extension 内，保留原 vendor 目录，不重复套一层 extension。浏览器扩展管理页点重新加载，确认0.10.4。关闭旧工作台，在真实申请页重新点工具栏图标；不要为了升级刷新尚未保存的申请。

已存资料是零散的项目背景/方案设计等片段时：工作台点“检查并整理已存资料”，查看原句整理出的项目描述，核对后保存。不会自动删除原条目，不会把别的经历或别的网站限制混在一起。

原文中的教育/项目从未解析并保存时，升级不能凭空恢复它们。重新选择原文字型PDF/DOCX并核对一次，或导入你自己核对过的facts JSON。管理页显示已确认的教育、项目、工作/实习记录数量，而不只报保存了多少条。

回到申请页点“填写简历”：只填可确定的普通空白项，缺少资料的跳过；敏感项、已有值差异仍需要本人确认。保留500毫秒回读，不自动保存、提交或勾选声明。填写不完整时，日志区分未匹配、尚未尝试和实际回读失败。

## 已实现的修复

- “科研与项目经历”等标题、无起止日期的编号项目、跨行项目标题、相邻分行的学校/日期和公司/日期可以进入正确记录。期刊发表年份不当作项目开始日期，“至今”不补造结束日期。
- 项目正文及明确职责/成果保留原句，未知文字留在未归类区域；名单式证书、奖励拆成对应条目，年精度不擅自补月份。
- 语言名称/掌握程度/听说/读写分别匹配；语言名称已填不代表熟练度有资料。
- 家庭情况分区识别与候选范围收紧：本人姓名/电话不能成为亲属资料；家庭的同名字段也不会阻塞个人信息区的姓名匹配。
- 原资料整理只生成预览，使用原导入确认与修订号校验。没有额外上传、遥测、权限或后台键盘监听。
- 填写计划被消费后仍保留实际引擎版本到日志；未尝试不算无资料或已经写入失败。写入计数兼容旧版固定数值日志名称。

## 验证范围

仓库只包含虚构源文和表单，不含用户简历及私人JSON。源文夹具保留两段教育、五段编号项目、一段实习及分行日期等结构。`test:recovery`验证解析、确认和整表填写：40个有明确来源的目标值逐项独立比较；无来源日期、家庭、健康、推荐码及语言等级保持空白，密码、声明及提交未操作。

`test:recovery-mv3`验证已安装扩展中DOCX上传→核对保存→原页鼠标点击→实际写入→回读→自动日志及已存资料整理。测试副本仅预授权本机虚构来源及工具栏来源标识，不验证真实权限弹窗或登录态招聘页面。CI结果以该提交的实际任务报告为准，运行前不能宣称通过。

本机当前不能获得已安装扩展后台，且本机HTTP导航被管理策略阻止；没有绕过策略。about:blank真实DOM回归与模拟接口界面测试不替代安装层。历史性能对照未在本轮重新测量；不宣称新的加速比例或全站覆盖。

默认免口令库仍为本浏览器未加密存储。上传给招聘网页的值由该网站接收，网站可能自动保存；本地处理不等于网站看不到已填值。MCP保持可选，使用时另有授权范围。
