# 0.7.0：本地DOCX导入、岗位资料方案与人工补填

基线：PR #5未合并的0.6.0提交`a2432435bf45c376e122e9b56edbac8e263f1549`。继续同一分支，不覆盖main，不回退长表单审阅、经历绑定、资料归并或临时MCP。产品版本0.7.0，桥接兼容协议仍0.4.3 / transport2。

## 实现

- `core/docx-import.mjs`：无依赖、无网络的有界ZIP正文读取，存储/deflate、字节区间与中央/本地目录一致、CRC、实际解压大小、独立XML与严格Word命名空间。拒绝加密/宏/分卷/ZIP64/重复项/路径越界/DTD/实体声明，解压流支持取消与超时。只读取普通DOCX正文与类型声明，忽略外部关系和未使用部分。
- `core/import-assistant.mjs`：只识别明确字段值和显式分区/经历；未归类段落保留，4000行/1000事实/2MB限制，不按日期或顺序猜学历、学校。
- `core/profile-presets.mjs`、`profile.mjs`、`vault-session.mjs`：有界命名事实引用方案，同一加密信封、revision与写入队列，备份和换口令保留方案，删除旧事实清理引用、空方案不回退全选。
- `workspace-worker.mjs`：可信工作台方案更新和单条复制检查；锁定/修订号不符/冲突/未核实拒绝，分享处理中不接受本地资料操作。
- `workspace.html/js/css`：独立导入页、原文/未归类检查、方案选择与管理、人工复制确认，旧界面的分页/映射/定位/敏感项审阅继续保留。

选择/切换方案不写网页、不发MCP；导入提取原文不直接保存或发送，只有经确认的事实才进入填写。复制离开密文保护范围，剪贴板历史/同步/其他程序可构成风险；本项目不读取剪贴板、不把复制标成自动填写成功。

锁定清理解析结果、未归类原文、方案与资料对话框。文件解析、保存、恢复、解锁、状态刷新和单项复制均带显示代次检查，旧异步结果不能在锁定后重新填回私人内容。大文件解压与UI原文尚在本机内存中，不声称JavaScript能够可靠清零所有系统内存/崩溃转储。

## 数据与兼容

DOCX8MB、正文XML4MB、文字2MB、512个ZIP部分、XML50000节点/80层；只读取UTF-8普通Word正文。图片、文本框、页眉页脚、批注、嵌入文件不识别，没有OCR、PDF或旧.doc支持。这些缺口在界面显示，而不是假装已导入所有可视内容。

方案最多24个、名称最多60字、只引用已存在条目，方案名称和ID同样加密。它不是多个独立人物身份或独立完整简历快照；同一事实修改会反映到所有方案。旧备份兼容，新备份的可选方案字段仍为schemaVersion1；0.7.0以前的程序会忽略新字段，降级后保存可能丢方案，已在安装说明明确警告。

没有扩展权限增加、运行时第三方包、网页自动提交、云端简历服务或新模型调用。引擎未修改，当前iframe只读、复杂跨域/级联/虚拟控件/附件回执没有因此完成适配。不宣称全站零误填或已超过任何竞品。

## 性能与证据

本轮优先减少反复勾选和逐条录入的操作步骤；没有整表耗时A/B测试，没有新增提速百分比。原engine.js、500ms最终回读和30/60/40展示预算不变。历史matched-performance job仍只手动触发，本轮不把skipped算通过。

测试只使用合成内容。ZIP夹具在运行时由Node/Python生成，不提交真实Word简历、测试口令、密文备份、配对文件或浏览器用户目录。截图展示虚构数据；CI原始JSON和源码/扩展打包产物用于复核。
