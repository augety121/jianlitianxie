## 交付内容

新的独立工作台包括填写、资料、安全三页；默认遮蔽内容，区分已核实、待确认和本次选择。手动编辑、TXT/JSON导入、加密备份/恢复、主动锁定、版本冲突检查可以实际调用本地资料库。没有PDF/DOCX自动解析、命名简历版本或原文检索授权。

直接本地填写不依赖桥接。可选临时MCP使用当前选中事实，五分钟有效、内存暂存、不写旧主档；安全中心可直接验证本机配对。旧主档路径保留，但需主动切换。

扫描当前可见可编辑主文档控件，借用已经验证的原生、ARIA、开放Shadow DOM、简道云等通用控件路径。选项、时间精度、重复经历不能确认时留空。可选枚举同源iframe只读；不自动给子框架写入，不显示无实现的定位高亮。每文档计划截断到1000字段、最多20个成功扫描文档，明确显示截断；不是扫描遍历的全局时间/节点上限。

截至这一提交前：Node **78/78**；原真实Chromium DOM **25/25**；目标校验DOM **16/16**；旧widget/panel界面 **10/10**；新工作台界面 **11/11**。

GitHub CI的该层结果由提交对应的installed-mv3 job和JSON产物给出。不得在任务完成前把pending写成passed，也不得把本机不支持的层伪装成测试通过。失败不使用continue-on-error掩盖。
