# 网申填写助手：0.4 本地加密与兼容性升级

基线：`695a20c58f5acf50496241bdba4f70fc6f7967b8`（0.3.1）。

## 目标

保留现有 MCP / Codex 路径，增加不依赖模型、不向桥接发送资料的浏览器本地模式。用户可以在插件内录入、编辑、导入及加密备份事实，然后扫描、匹配、逐项预览、明确授权填写和核对回读。真实简历、个人信息、配对码不得进入公开仓库。

塔塔网申帮助页 https://www.tatawangshen.com/plugin-help 是用户指定的产品目标。本次文本抓取返回零行正文，不能据此捏造其详细能力、内部架构或声称已经达到相同成功率。真实招聘平台需要逐站验收，浏览器夹具通过不等于官网通过。

## 实施与验收

1. 加密资料库：Web Crypto AES-256-GCM、PBKDF2-SHA-256、随机 salt/IV、密钥仅驻留工作进程内存、15分钟空闲锁定（工作进程被回收时可能更早锁定）。导出仅密文，错误口令或损坏备份不覆盖数据，资料更新带版本冲突检查。
2. 可信界面与消息边界：资料读写只接受扩展自身管理页，网页不能解锁、读取完整主档或发起本地填写；本地路径不调用桥接 API，不使用 sync 或第三方遥测。
3. 填写执行：按当前标签页和扫描绑定，预览后只下发所选字段值；已有值保留、重复经历须消歧、未知事实留空，不自动点击同意、保存、下一步或提交。
4. 兼容性与回归：原生输入、下拉、多选、日期、受控输入、Shadow DOM、动态重绘、重复记录及故障路径使用虚构资料验证。每次发现问题先补失败用例，再修复并完整回归。
5. 交付：PR、测试脚本、安装说明、公开的已验证/未验证范围。没有真实站点测试证据不得写“全站通用”。

## 隐私边界

本地资料库的加密不会自动加密旧桥接的 profile.json / evidence.json。两条路径明确分开；不将解锁资料静默复制进旧明文主档。选择 MCP 时，授权共享的数据会进入 Codex 上下文；填到招聘网页的值会交给该网站，网站也可能自动保存。认证加密不能防止被攻陷的浏览器、解锁时的本机恶意程序或招聘网站使用已经填写的数据。忘记口令无法恢复；修改口令不让已经下载的旧备份失效。
