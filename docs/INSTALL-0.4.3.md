# 0.4.3 安装与操作

## 升级

备份原扩展目录和私有资料。已有加密资料的先导出密文备份，口令另外妥善保存。不要卸载扩展、清除扩展存储，或把私有目录放到公开仓库。

本地模式：把扩展包解压，进入 edge://extensions 或 chrome://extensions，启用开发者模式并加载其中的 extension 文件夹。旧安装优先在原路径更新并重新加载；目录变化可能产生不同扩展身份，资料不会自动迁移。组织策略不允许安装时由管理员决定，不绕过策略。

MCP 用户：更新完整源码中的 bridge 和 extension，在 Codex 停止旧 resume_fill 实例再重连；不要关闭所有 Node 进程。保持原 RESUME_DATA_DIR，私有目录必须在源码外。入口仍为 Node.js 22+ 运行 bridge/server.mjs。出现版本不兼容提示时不要继续用旧进程填写。

## 本地资料和填写

从具体申请页点击插件工具栏图标，打开工作台；不能从搜索结果页或扩展设置页猜测目标。创建至少12个字符的独立口令，不要复用网站登录密码。遗失口令无法恢复。

“我的资料”可新增或上传 TXT / facts JSON，最多2MB、1000条。粘贴文本按每行“字段：内容”处理，多行描述用编辑器或 JSON。PDF / Word 自动解析尚未发布。资料导入后为待核实状态，逐条检查内容、分区、来源和经历标识，再确认已核实。不同学校/项目/工作经历用不同标识，不要让同名起止日期跨经历匹配。

勾选本次要用的已核实资料。新增条目不会必然加入原选择，可用“选中已核实资料”重新选择。回到填写工作台，先在网页展开所需区块，再扫描。预览默认隐藏值；“显示本次待填内容”仅影响展示。敏感项默认不选，必须本人另行确认。

用资料映射消除歧义，核对位置、来源与内容后勾选授权，再点击“填写勾选项”。已有网页值不覆盖；要修正的先在网页自行清空或更正后重扫。一次计划仅执行一次；新扫描、改资料、改映射、页面导航、超过5分钟或锁定都会使旧计划失效。

“扫描同源嵌入表单”需要单独授权 webNavigation，只读取当前标签页同源文档的可观察字段。此版本嵌入文档为只读，需单独打开后点击工具栏重新授权填写。跨域 iframe、隐藏区块、复杂级联等仍需人工处理。没有可用的精确高亮功能；根据工作台标签和经历核对。

查看逐字段回读。500毫秒回读仅证明该时段控件保留值，不证明服务器接受申请。验证码、声明、保存和提交由本人完成。网站可能在输入时自动保存。

## 直接把本地资料用于 MCP

先启动新版桥接，在工作台“安全中心 → MCP 本机配对”粘贴本机 bridge-token.txt 的64位配对码。点击验证，只有固定本机服务确认版本和身份后才保存。不要把配对码贴到聊天、Issue 或源码。

回到本地填写工作台，选择所需资料并扫描主文档。勾选临时分享说明，点击“授权本次资料给 MCP”。只发送所选已核实资料与主页面结构；网页已有值和经历锚点被遮蔽。桥接临时内存有效期5分钟，新库随即锁定。原文、其他未选资料、旧磁盘材料不会自动加入授权。

在 Codex 请求读取 form_context，必要时用 profile_search / form_prepare 生成计划；本人明确要求填写后才用 form_fill，最后检查 form_result。queued 不是成功。临时模式 source_search 不读取旧证据，profile_upsert 不修改旧明文主档；需要修正事实请撤销、回本地解锁编辑再授权。

“撤销本次 MCP 授权”需要收到本机桥接确认；连接失败时会报错，不假装已经撤销。最多5分钟后桥接自动拒绝后续读取。已发送给网站或模型的数据无法撤回。关闭工作台会尝试锁定与撤销，但崩溃/断线不保证即时送达。

确实需要旧主档时，主动选择“打开原 MCP 主档模式”；旧主档仍是明文，新库不会写进去。旧面板不再自动连接或从本地模式偷偷读取主档。

## 停止、备份与故障

停止保留已写内容，不回滚网站。正在执行时显示 stopping，等待实际回报后才结束；页面崩溃、休眠或响应丢失时先人工核对，再重新授权，不盲目重试。

导出只有密文；恢复要使用该备份原口令并确认替换，错误口令或损坏数据不覆盖原资料。换口令不会使下载过的旧备份失效。主动锁定会清理页面中的资料、导入文本、预览和结果；15分钟空闲/后台回收后需重新解锁。

兼容性反馈只提供虚构最小页面、控件类型和步骤。计数诊断不含URL、值或字段错误原文。不要提交真实网页 HTML、截图里的个人信息、Cookie、文件或配对码。
