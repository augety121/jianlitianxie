# 0.7.1 本地候选版：安装、日志与问题反馈

## 先确认版本来源

这份包是会话本地构建的0.7.1候选，包含0.7.0导入/资料方案和本轮日志。GitHub现有运行代码仍是0.6.0；PR #6只修正文档与反馈模板，没有新日志运行代码，不能用GitHub的Download ZIP代替本包。README、package.json、manifest.json、工作台和诊断页产品版本均为0.7.1。桥接兼容协议0.4.3 / transport2是另一项标识。

## 安装或升级

先备份原扩展目录及私有资料；已有加密库先导出密文备份，口令另行保存。不要先卸载扩展或清空浏览器存储。升级尽量保持原安装路径和扩展身份；不同路径可能成为另一扩展，资料不会自动出现。0.7.1包含资料方案，降级旧版前一定备份，旧版不认识新元数据。

解压扩展包，在Chrome的chrome://extensions或Edge的edge://extensions打开开发者模式，选择“加载解压缩的扩展”，选中包含manifest.json的extension目录。组织管理限制安装时，请由管理员处理，不修改或绕过策略。这个包不是商店签名安装包。

MCP用户用完整源码包，同时更新bridge和extension，私有资料目录继续放在源码外，只重启对应resume_fill桥接，不结束所有Node进程。主文档入口仍是Node.js 22+运行bridge/server.mjs。原配对保留，出错时在安全中心核对本机桥接版本/状态。

先用完全虚构资料检查本机环境的导入、扫描、勾选和回读。实际浏览器详情里确认插件显示0.7.1，再进行测试。每次升级后在具体申请页面重新点击扩展图标或重新打开工作台，避免使用旧页面脚本。

## 复现并导出一份有用的日志

1. 从工作台侧栏或旧MCP面板点击“诊断日志”，选择“开启30分钟记录”。默认不开启，不自动上传。
2. 保留具体申请页面，回工作台按平常流程复现一次问题。记录你按过哪些按钮、预期与实际行为；不要连续重复执行同一个失败计划。
3. 回诊断页选择“停止记录”。筛选某次操作或“异常及待处理”，查看固定原因码和建议。工作台的“诊断 #N”对应本次扫描中的字段编号；重新扫描、映射后需按新编号核对。
4. 点击“预览将导出的日志”，检查内容后导出所选范围JSON。文件没有自动上传到GitHub、聊天或外部服务。
5. 提交日志时另写产品版本、Chrome/Edge版本、使用本地还是MCP、控件类型、步骤及预期/实际表现。个人字段名、完整岗位URL、公司名和真实输入值不必写入；需要页面结构时用虚构最小页面代替。

例如只需说明：“本地模式，扫描后选第2段教育经历，诊断#8为地区下拉框，预期出现城市选项，实际没有弹出；原因码TARGET_BLOCKED”。不要为了定位问题附整份简历、网页HTML、Cookie、配对码或含个人信息截图。

## 正确理解结果

“可填写/ready”只代表计划匹配；“回读通过/verified”只代表程序检查时控件保留了目标值，不代表网站服务器已保存、提交或接受申请。日志只有“开始”可能是操作进行中、录制被停止或后台中断，不是必定失败，不能据此盲目重试。

日志保留固定状态码，不保存错误原文或调用栈。很多格式错误可以分类，但未知组件不一定仅凭日志确定根因；仍需补充操作步骤与虚构复现。界面处理过的部分导入错误可能没有详细诊断事件。

## 隐私、容量和清空

记录的是活动元数据，并非加密的另一份简历：没有字段标签、真实值、URL/域名、文件名/路径、HTML、截图、Cookie、密码、配对码、文档ID或原始报错。导出没有绝对时间，只保留相对时间；插件版本、计数与步骤仍可能说明使用情况，分享前必须预览。

最多600条事件、每次操作最多400字段详情，优先保留异常；省略数量会显示。24小时前数据在下一次日志读取/写入时淘汰，不承诺后台完全不活动时即时物理擦除。“清空并停止”停止录制并清除日志，旧操作的迟到结果不能重新写回，不会删除加密资料库。

后台日志按批异步写入，不逐字段写磁盘，不会为日志失败再次填写；旧独立面板的可选诊断消息等待上限250毫秒，极端情况下可能漏记。停止录制不停止正在进行的填表；需要停止填写请使用工作台/面板中的停止按钮，再核对已写内容。

## 保留的能力和未完成范围

本地DOCX文字提取、资料方案、单条复制、经历绑定、长表单分页及临时MCP继续保留。DOCX不理解所有排版，图片/文本框/页眉页脚等可能未提取；不支持PDF或旧.doc。方案是共享事实引用清单；复制后内容处于系统剪贴板，不受库加密保护。

同源iframe仍只读，复杂跨域、级联、虚拟控件和附件回执没有因新增日志而自动解决。500毫秒回读保留，没有新的全站覆盖率或整表提速结论。原loopback桥接不是TLS；已受控操作系统/浏览器及招聘网站本身可见已填写的值。
