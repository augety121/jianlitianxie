# 0.6.0：可审阅的长表单与控件兼容性

基线：用户上传的 main 源码归档 `3b4227d4ca0c1fb264f3b52820577ed555180915`（已合并 PR #4，版本0.5.0）。保留已有 JSON Resume 导入归并、整段经历绑定、本地加密库和临时 MCP 协作。不覆盖旧私有资料，也不替换成早期0.4.3代码。

## 用户可见改动

工作台调整为深色侧栏、明确的任务状态、分区筛选、字段搜索和紧凑审阅行。扫描边界放入可展开说明，已核实/可填写/待处理各自计数，不把零待处理当作已覆盖整个网站。

长表单每页30项，资料库每页60条，映射对话框每页40条。页码只是展示范围，不是扫描上限；所有选择仍按字段ID保存。切换搜索、页码和分区不会重新勾选被取消的字段，已选但未显示的条目有数量提示。“本次已选”筛选可以集中复核；“必填待处理”现在只包含未匹配或需人工处理的必填项，不再混入已准备好的字段。

每个字段不再常驻一份包含所有资料的 select。点击“更换资料/选择资料”才生成一个有界对话框，可按字段、经历或别名搜索；只从本次所选且已核实的资料中筛选，并考虑来源、分区和已绑定经历。候选默认隐藏内容；不同字段名的手动映射另行确认，再清除旧审阅授权。关闭或锁定时移除候选DOM。搜索默认不检索被隐藏的资料内容。

同一240字段、240事实的测试中：审阅区仅呈现30个字段、没有常驻资料下拉框；资料页60项、映射对话框40项。相对于旧版为每个字段构造全部资料选项的方式，这是DOM规模控制，不是实测整站速度百分比。最终500毫秒回读仍保留，没有为了提速删验证。

## 控件修复

- Ant Design等表单中，原生单选组优先使用本组的字段标签，不再把外层“基本信息”legend当作性别等每一组的名称。
- 增加空 contenteditable 属性及 plaintext-only 富文本输入识别，避免重复扫描嵌套编辑区。
- 英文教育起止时间、院校名以及 Emergency contact 分区补充明确语义；个人电话与紧急联系人电话不混用，年月不补成某一天。
- 透明祖先、隐藏区域、验证码及密码型 autocomplete 不进入可填写快照；跨开放Shadow DOM检查祖先可见状态。
- 普通原生输入写入前，在新建且脱离页面的原生控件上检查浏览器格式、数值范围、步长、日期边界及长度；无效值返回 invalid，不先写进网页再发现不合格。该校验不触发网站监听器。
- 扫描报告隐藏/禁用/只读/密码类/超出1000字段上限的数量；仍不等于跨页面、闭合Shadow DOM或全部网站覆盖。
- 本地计划期限下发执行器，异步下拉等待和逐字段操作检查期限；过期后不选择迟到的选项。不保证浏览器挂起时立即中断已经发生的副作用。

## 隐私修复

工作台在第一次异步目标检查前串行占用分享入口；同一时刻只允许一次资料分享准备。准备期间收到撤销或锁定，则拒绝后续发送。加了真实工作台/加密库依赖的取消竞态测试。

扩展后台和原面板的认证请求拒绝HTTP重定向并禁止响应缓存。仍只连接原固定loopback桥接；没有新增host权限、外部模型、遥测或资料云。loopback HTTP仍不是TLS，也不能承诺抵御已经控制操作系统/浏览器的进程。

修复锁定工作台的状态轮询反复清空用户正在输入的恢复口令问题；真正从解锁变锁定时仍清除资料与对话框。备份口令不保存到库或GitHub。

## 实际验证层级

本机 Node 99/99；既有真实控件DOM25/25；目标守卫16/16；整段经历DOM4/4；新增兼容控件15/15；原面板UI10/10；工作台UI14/14（包含240字段压力流程）。对应命令与报告来自本次代码，不借用旧版本通过数字。

工作台UI使用真实Chromium和真实Node加密/工作台模块，但Chrome IPC及网页执行器为替身。新兼容场景使用真实DOM、事件及执行器，独立读取控件值，不是15个招聘平台。所有资料是虚构的。

本机安装MV3尝试未获得service worker，保留失败/不可用日志，不修改浏览器管理策略。GitHub的 installed-mv3 任务对实际安装扩展、真实本机桥接及虚构localhost页面另行验收；最终状态看本提交对应的 Checks / PR，不把本机DOM测试代替安装验收。该测试预授予测试副本的本机来源和文档枚举权限，不验证用户实际点击权限弹窗或所有品牌浏览器。

## 修复记录

新兼容测试首次测试打包器不支持命名重新导出，随后在 about:blank 缺少安全上下文 randomUUID；修正仅测试打包与测试身份生成，不改变发布ID安全机制。旧UI测试适配新的展开式覆盖说明和按需映射对话框，保留原断言。

新增脱离页面的原生校验触发了旧故障注入的setter计数：校验与实际写入各调用一次，测试误判为重试。现校验使用初始化时捕获的原生setter，真实写入继续保留原路径及故障注入，确保一次不确定写入立即停止后续字段；16项守卫完整复测通过。失败日志保留在交付验证包中。

## 仍需逐站验收

同源iframe仍只读，跨域iframe、闭合Shadow DOM、复杂级联地址、虚拟滚动、专有附件回执和全部招聘平台未获得全面验证。用户需主动展开区块/创建记录/进入下一页再扫描。没有PDF/DOCX解析或自动提交，也没有同条件塔塔对照数据，不能宣传全站无误填或已全面超过竞品。
