# 0.6.0 安装与使用

已有安装先导出加密备份并保管口令。在原目录更新公开源码，再于 Chrome/Edge 扩展管理页面重新加载；不要先卸载或清空浏览器存储，不要把旧的个人文件复制到公开仓库。首次安装选择“加载已解压的扩展程序”，指向包内 `extension` 文件夹。

本地填写无需 Node、模型密钥或 MCP。进入具体申请页，点击工具栏图标，然后在“我的资料”导入并核对 TXT、facts JSON 或 JSON Resume。选择本次使用的已核实条目。不同教育、工作和项目记录沿用不同经历标识；不要凭区块先后顺序判断本科或硕士。

返回填写工作台，展开网页相关分区后扫描。先对空白经历区块选择对应学校、公司或项目，再使用“必填待处理”和分区/字段搜索检查缺项。每页30项只限制展示，不减少扫描结果；翻页和搜索保留选择，底部显示未在当前页显示的已选数量。需要检查全部待写内容时选“本次已选”，逐页核对。

“更换资料/选择资料”打开一次性的资料对话框，默认遮蔽候选内容，只搜索标签、分区、经历和别名。候选列表可翻页；同义字段优先。字段名不同时需要再次确认两者含义一致，整段已绑定时不能把其他经历的事实映射进来。手工映射不会绕过网页原生格式、范围或计划身份检查。

最终核对字段与内容，勾选审阅声明再填写。已有内容保持不变，验证码、协议声明、附件服务器回执、保存和提交由你本人操作。收到 invalid 表示网页格式/范围不接受；先修正资料或手动处理，不要反复重放同一计划。停止保留已经写入的内容。

需使用 MCP 时同时更新 `bridge` 和 `extension`，只重启对应 resume_fill 进程；桥接兼容协议仍为0.4.3/transport2，产品版本0.6.0不是协议断裂。安全中心验证本机配对码，再从工作台明确分享本次所选资料，5分钟临时授权；不要把口令/配对码发送到聊天或GitHub。原明文主档与加密库仍分开，升级不自动加密/删除旧文件。

同源嵌入文档本版仍只读，需独立打开成主文档才能填写；跨域、隐藏/折叠内容、下一页和全部厂商组件没有通用成功保证。每种真实系统需要单独验收，不能把扫描数量理解成官网完整覆盖率。组织管理策略禁止安装时由管理员决定，不绕过管理规则。

开发验证：`npm test`、`npm run check`、`npm run test:compatibility`、`npm run test:workspace`、`npm run test:mv3`。界面布局截图及分层报告见PR和验证包。无需构建或额外运行时第三方服务。
