## 仅在本地工作目录实现的候选功能

1. 单独的导入简历页面，DOCX正文与表格文字本地提取，明确字段值成为待核实草稿；未知段落保留，由本人归类，不发送云端解析。
2. 加密命名资料方案，保存事实引用而非相互独立的简历副本；切换后需要重新扫描和授权。
3. 本人确认后逐条复制已核实资料，供不支持自动填写的控件人工补填；不自动粘贴、不把复制计为填表成功。
4. 锁定与异步文件读取/资料返回之间的显示状态防护，避免迟到结果重新显示私人内容。

这些功能目前**不在本PR的可执行代码中**。本地候选包与GitHub源码包不是同一个版本，不能混用或宣传为已同步产物。

## 范围边界

DOCX提取不是任意排版的语义解析，图片/文本框/页眉页脚等未支持；仍无PDF或旧.doc导入。方案是共享事实的引用清单，不是完整独立简历。复制后内容进入系统剪贴板，可能被历史/同步/其他程序读取，不受资料库加密保护。没有新增网络服务或权限，MCP兼容路径保留，引擎和500ms回读未改；本轮没有新的整表耗时对照或真实官网覆盖率。

同源iframe只读、复杂跨域/级联/虚拟控件等限制仍在；本机桥接不是TLS，静态加密不能防止已被控制的操作系统/浏览器。没有全站零误填或绝对防截取保证。
