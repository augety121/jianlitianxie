# 0.15.1：完整资料核对和经历选择保持

2026-10-02。承接 PR #18 和既有 Spec 的 V05、V09、V10、V23、V25。本轮重点是已整理的大资料库进入日常填写后的更新流程，真实清空—回填—恢复门槛继续保留。

## 复现与修改

1. 选择项目甲后，重新导入并替换它的名称字段，旧字段 ID 被移除，之前保存的选择指向旧 ID，导致该项目无提示地退出填写范围。新增反例在旧代码上得到空选择。保存现在按原有分区、经历标识和网站范围对应同一记录，迁移其选择；未选经历和新出现的经历保持未选，空选择仍为空。没有显式选择过的版本继续默认全部。
2. 两个不同经历携带相同导入 recordId，会共用选择 ID；只勾选一段可能选中两段。旧代码反例只能生成一个唯一 ID。目录现在保留无冲突的已有 ID，并为冲突项使用各自唯一的字段 ID，避免导入元数据扩大本次选择。分区和网站范围仍参与分组，不能因名称相同而跨域合并。
3. 普通完整 JSON 导入原先平铺全部字段，只有旧资料修复才按经历组织。现在普通导入也按分区、经历和网站范围分组；每段统一编辑所属经历、显示所选条数，可批量勾选本组新增项或取消。本来有差异或文件冲突的组默认展开；批量新增不会顺带批准旧值更新。无明确经历的字段继续保留逐项归属，不自动合成经历。
4. 记录选择显示中文域名、已选/全部计数及网站范围，解释新增记录与默认全部的不同情况。权限、确认边界、日志脱敏及不自动提交保持原契约。
