# 0.7.0 本地候选版安装与使用

本包不是GitHub当前分支代码：源码同步被工具安全检查拦截，GitHub PR #5仍为0.6.0运行时代码。本包仅完成本机分层测试，安装后扩展测试尚未验证，先备份并用虚构资料试用，不要依据旧版CI视为正式发布。

## 从当前安装升级

先导出加密备份，另行妥善保管口令。保持扩展原安装目录，在原路径更新后点击重新加载，不要先卸载、清空浏览器存储或将私有资料复制到公开仓库。完整源码包含bridge和extension；MCP用户同时更新两者，并只重启自己的resume_fill实例。产品版本0.7.0，桥接兼容协议仍是0.4.3 / transport2；不要把协议标识误认为扩展未更新。

初次使用：在Chrome/Edge扩展页打开开发者模式，加载包中的extension文件夹（含manifest.json），进入具体申请表点击工具栏图标。创建独立长口令，再开始导入。由组织管理的浏览器需要管理员允许加载扩展，不绕过策略。它是开发者加载包，不是应用商店签名安装包。

## 从Word简历开始

进入“导入简历”，选择或拖入一个本机DOCX文件，最多8MB。TXT和JSON最多2MB。浏览器直接读取Word正文段落与表格中的文字，没有云端解析、模型请求或原文件上传。提取最多2MB文字，XML最多4MB、ZIP最多512个部分；解压超时或超过限制会报错，不自动保存不完整资料。

正文之外的页眉页脚、图片、文本框、批注、嵌入文件不识别；修订中删除的文字不导入。ZIP64、加密、宏文档、PDF和旧.doc不支持。文件能被打开不代表所有可视文字都被提取，务必对照原简历。

“简历段落（辅助归类）”只把明确“字段：内容”或两列字段/值识别为草稿。例如：

```text
基本信息
姓名：虚构候选人
教育经历：第一段教育经历
学校：虚构院校
入学时间：2020-09
```

明确的经历标题可作为分区/经历标识；没有明确字段的项目描述、日期行和多列数据保留在“未归类”区，不猜测学校、学历或记录顺序。选择一段，点击“把本段整理成一条资料”，自己指定字段名称、分区、经历和来源，再保存。标签为空时不能保存。已识别草稿保存后转到“我的资料”核实，未归类原文仍保留，不被静默丢弃。

使用facts JSON或JSON Resume时可选“字段列表 / JSON”；保留既有重复比较：相同内容跳过，变化默认不替换，文件内同一字段冲突不写入。导入本身不验证真实性，新增/变更条目在本人确认前不参与自动匹配。

导入文字只保留在当前界面内存；主动锁定会清理。打开其他文件、清除导入或关闭页面会丢失尚未保存的草稿。文件读取过程中锁定，迟到的结果也不能重新出现在界面。不要依赖浏览器刷新保存尚未整理的原文。

## 为不同岗位保存资料方案

先在“我的资料”勾选本次适用条目，回到“填写工作台”选择“保存／管理方案”。输入方案名称创建；最多24个方案、名称最多60字。更新已有方案需要选择目标并确认，用当前选择替换旧方案的引用清单。

方案不是独立简历副本，只引用同一个加密库中的事实。修改共享事实影响所有引用它的方案；需要不同项目表述，应创建不同资料条目再分别选入方案。导入替换使用新ID、删除旧条目时旧引用会移除，需重新检查方案。方案变空时保持空选，不会把整库资料自动选上。

切换方案只改变条目选择，并使之前扫描/映射/授权失效。待核实、冲突或密码类条目不能因此成为可填事实。随后重新扫描、绑定经历、检查逐项来源，再明确授权填写。删除方案不删除原资料。

方案名称、条目ID都随资料加密和导出备份。新版本兼容读取旧备份；0.7.0以前的版本不理解方案字段，降级后保存可能丢失方案元数据。不要用旧版覆盖新库；旧文件中原始事实不会因此变成独立副本。

## 自动填写不支持时的辅助路径

在“我的资料”点击某条已核实资料的“复制内容”，先确认将把它放进系统剪贴板。后台再次检查锁定状态、资料修订号和条目资格，只返回这一条内容。然后由本人核对目标字段并粘贴；不要把个人电话粘到紧急联系人或把另一个项目日期粘到当前经历。

系统剪贴板不是密文库。剪贴板历史、跨设备同步和其他本机程序可能读取它；敏感条目应谨慎复制。扩展不读取剪贴板，不自动粘贴、不自动清空/覆盖剪贴板，也不能撤回已经复制的内容。浏览器拒绝写入时会提示失败，不循环申请权限或自动重试。人工复制不计为扫描到、填对或服务器保存。

## MCP和原有填写

本地导入、方案选择和自动填写不依赖Node/MCP。需要Codex协作时：选择方案→扫描主文档→在安全中心验证本机配对→明确授权所选事实。临时MCP仍只在内存保留最多5分钟，不写旧主档；方案名称和原Word文件不发给MCP，只分享本次选择的已核实事实及允许的页面结构。换方案之后要重新扫描授权。

原MCP明文主档模式需主动切换，仍保留原流程。旧profile.json、evidence.json和以前日志不会自动加密/删除。MCP桥接仍使用固定本机HTTP和配对码，不是TLS，也不抵御已控制系统/浏览器的程序。

当前同源iframe仍只读扫描、跨域和复杂级联/虚拟控件需人工处理。附件、验证码、声明、保存和提交由本人完成。不把“回读通过”当成网站已接收申请；停止不回滚已写内容，异常先核对网页，不盲目重试。
