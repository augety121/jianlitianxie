# 0.8.4：有资料先填，缺项跳过，补完再记住

## 使用流程

在真实申请页点工具栏插件，再点“填写简历”。已有资料且唯一匹配的普通空白项直接填写；没有资料或不确定的项直接跳过。缺项列表默认收起，不要求先逐项选择资料，也不阻塞其它可填项。已有内容不覆盖，敏感项仍需另行确认。

接着直接在招聘网页手动补上剩余内容。**不要先刷新、跳下一页或重新扫描**，在当前页点“我补完了，记住内容”。扩展打开一个本地确认窗口：查看检测到的内容、勾选需要留下的条目，再点“已核对，保存到本地”。下次匹配会使用这些已确认资料，不需要重新导入整份简历。

默认只用于当前网站；本人可勾选允许其它网站复用。教育、工作、项目等记录需要准确的经历名称；已有学校/公司锚点只能唯一对应一段记录时会预填，否则要在这次保存预览里明确指定。相同内容不重复保存，不同的旧内容不会自动覆盖。

## 这次具体修复

原引擎的已有经历锚点识别包含“公司”“单位名称”，但漏掉“企业名称”。当网页已填写企业名称、本地资料使用公司名称时，同段的部门等字段可能无法依靠该值确定所属经历。新增虚构两列实习表单测试，验证企业名称匹配自己的部门；没有把项目经历描述跨区填入实习经历。

补充明确的“部门/所在部门/部门名称”对应和“自我评价/评价内容”对应，以及字段末尾帮助问号处理。不做全局模糊匹配，不把未知事实猜成个人信息。用户截图没有原始DOM和本地资料全文；旧上传诊断的productVersion是0.8.1，不能用它证明当前版本所有缺项的根因或保证所有真实缺项已经修好。

## 保存边界

没有添加键盘监听、全站记录、云端上传或MCP调用。“记住内容”只在本人点击时读取本次扫描之后由空白变为非空的受支持原生输入、文本域和原生单选下拉，预览后再次确认才保存。网站自身也可能更新值，因此它不是自动认定“本人输入且事实正确”。

插件已经尝试写入的字段、扫描前就有值的字段、隐藏/替换/改名控件、格式无效内容、密码/验证码/声明/附件和不支持的自定义组件不收集。原生下拉保存显示文字，不保存内部选项ID。收集最多100条。当前页新扫描、修改主档、导航、取消或会话到期会使旧预览失效；保存前再次读回，值变化则不落盘。确认小窗本身在后台回收后需要关闭重开，旧确认票据不恢复。

读取上下文最多30分钟；只读起点的匿名ID、资料修订号、URL摘要保存在可信浏览器session存储，后台回收后可以恢复，但不保存字段内容、原始URL或确认小窗票据。整个浏览器重启后该会话失效。确认窗口票据最多5分钟，绑定真实目标文档、资料修订号和实际新建扩展窗口。普通页面不能借票据读回私人候选，也不能直接传任意事实写入主档。采集和保存不操作网页输入，不执行网站提交。

免口令资料仍使用独立的浏览器本地未加密存储；本轮不改变这个已经明确告知的选择。日志默认本地异步记录固定阶段、数量和状态，新增learn阶段，不记录个人内容、网址、字段名称或原始错误。已填到网站的值可由该网站接收。无法承诺抵御已攻陷的浏览器或操作系统。

## 测试与已知边界

逻辑测试覆盖明示确认、重复/冲突、经历歧义、网页冒充、不同窗口、修改资料、重新扫描、导航和保存前值变化。真实DOM测试覆盖企业名称锚点、保存下拉显示文字、密码/旧值排除、插件自动填写排除、节点替换/改名/隐藏。真实确认UI验证敏感项默认不选、预览清理与570/390像素布局。

新增安装场景：自动填已知资料并跳过缺项 → 本人填写缺项 → 打开真实扩展确认窗口 → 单次保存 → 下一申请页自动复用。测试代码已经加入本地源码，但本轮源码同步被安全检查拦截，所以没有0.8.4远端CI结果。本机尝试加载扩展时未能取得service worker，安装层记为未验证；完整页内交互测试的测试URL被管理策略阻止，未绕过策略。

实现时浏览器回归发现：填写执行结束会清理一次性写入快照，导致随后的补充读取失败。改为独立的只读采集快照，不延长或恢复写入授权。取消同时清理两者。保留这个失败日志与修复后的回归，不删除原一次性计划限制。

跨域框架、动态新增但未扫描的经历、复杂级联及虚拟组件仍需进一步适配。要记住这些字段前需在展开后重新开始一次扫描；本版本不采集任意新出现或无法定位的控件。500毫秒最终回读保留，没有发布本轮新的整表提速数字。
