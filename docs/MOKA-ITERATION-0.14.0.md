# Moka 实施与验证记录 — 0.14.0

候选构建标识：`moka-20261002.1`。本次基于已合并 PR #15、#16 的 main（`5b83905`）实施。本文不宣布 Spec 全部完成。

## 实现

1. 组件目录增加 Moka 的稳定类名前缀，区分 `sd-Select-container` 的选中显示节点与空搜索框。不依赖 CSS 构建后缀、不复制第三方插件代码、不调用站点内部接口。单个逻辑编辑器才能识别为一个控件。
2. 修复原生 `label` 外壳阻断组件识别、深层年月控件丢失分区、十条获奖记录错分组的问题。起止年月区分开始与结束；“至今”选中且仅有两个分量时只识别开始年月，不改动复选框。
3. 五类记录包含教育、实习/工作、项目、语言、获奖。按真实 identity 字段计算已确认可用记录，缺少来源不新增。最多每类 20 条、单任务新增 20 条；有多个候选的空记录仍须一次整段确认。
4. 新增后同时核对原输入值、复选框和显示节点。若新增改变了旧记录的显示值，停止继续新增并返回未知结果；不重复点击。
5. 可确定的普通字段先填写并回读，再重新扫描、创建待确认记录票据。确认前后使用同一 taskId，计数累计；重新扫描后更新“记住内容”的基线。
6. task/添加/扫描/绑定/填写日志关联同一 taskId。schema 3 继续读取旧记录，保留固定字段白名单；输出组件 family、执行阶段、是否已尝试、extensionId、构建标识及运行版本。没有个人值、原始标签、申请 URL、正文或原始异常。
7. 整页存在 missing、review、未核实的 preserve 或未完成新增时，结果为 partial。`verified` 仍仅表示本页回读，不表示保存或提交。零目标仍为 no-eligible-fields。
8. Manifest、package、页内入口、引擎和新增控制器统一为 0.14.0。既有资料恢复、多简历库、文本变体、MCP 流程保留。

## 真实内置浏览器观察与阻断

已复用登录态打开用户指定申请页，核对到原有 18 段记录。只读检查了实际输入外壳、显示节点、年月嵌套结构，并读取网站 console。未清空字段、未删除记录、未上传附件、未保存或提交申请。

出生年月输入显示有年月和年龄，但打开后的站点日历标题为 `0年`。console 有站点 Moment 日期解析格式警告；目前只能确定两项观察同时存在，不能认定因果关系。保持原值；该独立只读日历不属于本次已通过的分离年月选择器测试，不能声称已经修好。

内置浏览器工具只开放 HTTP/HTTPS 页面操作；尝试扩展管理入口时明确返回 URL 安全策略禁止，并禁止间接执行、原始 CDP 或其他规避手段。工具也未提供加载 unpacked MV3 的正式能力。当前没有本项目扩展的可信运行身份，因此真实插件清空—回填—读取插件日志—恢复闭环尚未执行。网站 console 日志不能冒充插件日志。

这项阻断需要宿主提供受支持的扩展加载入口和可核实的运行身份。不得用 Codex 代填、把代码注入真实页面、换用户浏览器或扩大权限来关闭本验收项。
