# 0.8.0 本地速填：使用、迁移与验收

## 日常只做三件事

第一次：在申请页点击插件 → 选择MD/JSON/TXT → 看一次导入预览 → “已核对，保存到本地并扫描”。新条目默认选中，变化默认不选；冲突、重复不会跟着写入。保存就是本人对所选事实的确认，不用再去另一个资料页面逐条确认。

以后：在申请页点击插件 → 自动读取已保存资料并扫描 → 检查匹配和重复经历 → “已核对，填写所选项”。无需口令、配对码、Codex或本地服务器。扫描是只读动作，填写和提交不是同一个动作。

要改资料：在“导入与管理资料”搜索字段或经历，打开“查看/修改”。保存后旧预览失效；重扫后使用新值。无须再导入整个文件。

## 存储选择

新的免口令数据键是 `resumePlainLocalV1`。首次保存明确确认未加密本地持久化，不使用浏览器同步。普通网页/内容脚本不能通过工作台API读取完整资料；可信扩展页只使用投影后的正常资料结构。

原加密键 `resumeVaultV1` 和历史MCP磁盘文件不被修改或删除。旧界面之所以需要重新输入口令，是关闭页时主动锁库，且密钥只在短寿命后台内存中；这是原安全设计，不是保存资料丢失。本地速填改用明确选择的未加密持久化，而不是把口令偷偷存进浏览器再称为安全自动解锁。

“从已有加密库导入”只解密读取、生成预览；错误口令不产生副本。只有随后确认所选项才把这些事实复制到新的未加密存储。复制后旧加密库保持原字节不变；未来两份数据独立，不自动同步。原口令不会持久化。共用设备继续使用高级加密库。

## 导入规则

优先使用包内模板。MD支持分区标题、子标题经历标识、明确字段和值、两列“字段/内容”表格。普通段落、代码围栏和不支持表格保持未归类提示，避免猜日期、学校或资格。JSON支持facts数组、简单字段对象、已有JSON Resume路径；缺少ID或来源会生成，文件声明的confirmed不会绕过本人核对。

同学校不同学历使用不同entity；同公司不同时段也用不同entity。使用整段经历绑定时先核对网页区块，再选择对应经历。不以网页序号猜本科/硕士。

## 自动日志与隐私

只记录本地速填操作，默认打开，可随时关闭。固定字段清单经过写入和导出校验；简历值、字段标签、URL、DOM、截图、口令、Cookie、原始异常不进入日志。日志为未加密操作元数据，不与资料库加密混淆。

每次最多300个字段结果；优先保留异常或未匹配项，并标注省略数。最多80次操作，下一次读取/写入时移除24小时前记录。导出相对时间，没有自动上传。网页字段#序号只在该次扫描内有效。

日志写入不阻塞填写，也不把存储失败当作需要重复填写。关闭后台、浏览器崩溃或存储挂起可能导致缺记录；不能从日志缺一行断定网页没被写入。停止不会撤销已写内容，最终提交由本人完成。

## 验证层次

Node回归覆盖：MD/JSON模板一致、加密迁移不改旧数据、默认日志投影和容量、重建后台后无需口令恢复、资料修订冲突、旧计划过期、MCP与本地互斥、未选敏感项不发送、日志存储挂起不阻断成功填写。

新UI回归使用真实Chromium界面和真实Node控制器，但Chrome API、网页执行及查询参数为测试替身。安装后回归另使用完整Chromium和临时目录：实际导入与扫描、填写后独立DOM读取、默认日志内容检查、拒绝页面冒充工作台、完整浏览器关闭重开后恢复、无效邮箱写前拦截，以及所观察请求中无外部服务或MCP。

CI未跑完前不写“全部通过”；结果以提交对应的JSON报告和Actions状态为准。本站点模拟通过不等于全部招聘系统支持。

机制参考：Chrome官方[storage](https://developer.chrome.com/docs/extensions/reference/api/storage)与[service worker](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers)说明。标准API机制不等于本扩展独立安全认证。
