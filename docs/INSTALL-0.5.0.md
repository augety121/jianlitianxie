# 0.5.0 安装与使用

## 安装 / 更新
1. 旧版本先在安全中心导出加密备份，记好原口令。
2. 保留原扩展文件夹路径，用新版源码更新，再在 Chrome/Edge 扩展管理页点重新加载。不要卸载或清空存储。首次使用可开启开发者模式，选择“加载已解压的扩展程序”，定位 `extension` 文件夹。
3. 在具体岗位申请表点击工具栏图标，创建或解锁本机资料库。默认本地模式无需 Node 或模型密钥。

## 只准备一次资料
选择私密的 facts JSON / JSON Resume 文件，点击解析。预览会显示新增、重复、内容变化和冲突。相同内容保留原有核实状态；变化默认不覆盖；一份文件自相矛盾的字段整组暂不导入。

保存后查看来源与真实内容，确认已核对的选中资料。真实个人文件自己保管；公开仓库只包含合成样例，不能从 GitHub 恢复你的个人数据。

支持 JSON Resume 的 basics、education、work、projects、awards、certificates、publications、skills、languages 中的明确白名单字段。未知扩展字段不导入；照片和证件附件由本人上传。没有日期精度升级：只有年月不能补成每月1日。

## 每个岗位的填写流程
1. 选择本次要用的已核实资料。项目描述以该岗位最新简历为准，可编辑对应项目事实；不要把多套相互不同的描述同时当同一字段。
2. 打开网站相关分区并添加需要的教育/项目记录，再扫描。工作台显示当前文档和覆盖缺口。
3. 对空白经历区块，点“查看网页区块”确认位置，再选择对应学校、公司或项目，一次绑定整段。每段字段会按语义重新匹配，绑定不等于直接填写。
4. 优先看“待映射”“人工处理”和必填项。核对预览，勾选要填写的项目，执行后检查回读结果。附件、保存和提交由本人完成。

## 已实现的边界
已有值保留；冲突不猜；不按记录排列顺序判断本科/硕士；日期、下拉选项及字数限制不满足时留待处理。网页跳转、重新扫描、资料修改、区块重排或字段变化会让旧计划失效。

主文档支持写入与定位；同源 iframe 仅扫描；跨域/折叠/下一页不能称已经检查。验证码、附件上传、自动新增复杂经历卡片和所有招聘网站的专有控件尚未全覆盖。页面变化后重新扫描，不能直接重放上次执行。

## MCP / Codex（可选）
继续使用兼容的0.4.3本机桥接协议。仅在主动配对并明确分享后，本次选择的资料才临时供 MCP 使用，5分钟到期；本地模式不需要这个步骤。协议版本与扩展产品版本各自维护。

## 验收范围
本次新增导入归并、JSON Resume、整段经历绑定和安全定位逻辑均有合成数据测试。用户浏览器权限校验失败时，不声称招聘网站验收通过。CI中的localhost模拟网页、真实Chromium DOM和安装后MV3测试也不等于全部官网兼容；实际结果以本次提交的检查记录为准。
