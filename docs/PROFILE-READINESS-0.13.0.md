# 0.13.0 实施记录：资料可用性、区域新增与简化操作

## 本轮依据与边界

用户最近日志包含多个历史版本。最新0.12.0扫描有102项：62项未匹配、37项保留、3项人工；可填为0。新增检查为no-source-records，各类目标数量0，同时分区标记section-ambiguous。40条已确认资料中31条是项目分区的未规范分类条目。个人日志及内容不进入仓库，本文件只记录定位所需汇总。

这不能证明40条资料都无用，或全部故障由一个原因造成。本轮对可复现的源资料片段与页面目录重名分别修复；不假装已经操作用户登录态页面。

## 实现

`profile-readiness.mjs` 使用已有来源过滤和新增目标规则，返回无值计数：已确认条目、可填写教育/工作/项目记录、可整理项目数量。页面不会收到候选正文或原始经历名称。

旧资料整理复用原有审阅与合并流程。规范化加粗/冒号片段标签；同名规范片段相互矛盾时不合并。按来源origin和entity分桶，保留完整原文，不从项目别名推断项目名称。预览是未确认草稿，只有本人确认后保存到当前简历。原条目不删除、其他简历不改动。

原页根据就绪状态显示整理入口，并导航到扩展自身的核对页面。导航参数只接受profile/logs/repair枚举；不允许网页请求原始预览。填完普通字段后仍可看到整理提醒，不要求重新上传已经保存的片段。

新增识别不再只计同名标题的数量，而是核对每个标题对应的受限区域和唯一新增按钮。无标记侧栏目录没有区域内新增按钮，不能阻断正文区域。两个真实区域或多个竞争按钮仍然阻断，未取消遮挡、页面身份、旧值不变、增长和总数限制。

字段识别跳过“请输入”“请选择”等确切的泛化提示，继续读取该控件本地明确标签；不据此扩大字段范围，也不凭空赋予语义。

日常页面保留填写和必要动作，辅助按钮折叠。日志可从原页进入；加密/MCP为高级入口，不移除任一存储/日志/保护能力。

## 回归

新增Node测试覆盖旧片段不是可用记录、显式确认后可用、来源隔离、家庭记录排除、格式化冲突和网页不能读修复候选。

浏览器测试含正文前后的无标记目录、两个实际新增区域，以及通用ARIA覆盖局部邮箱标签。旧主干与新代码可在同一测试下比较，失败样本不从分母删除。

新增真实安装用例从7条虚构旧资料起步：普通三项填写，原页打开两段修复预览；未确认前资料不变，确认后只增加2条描述；明确允许后建立2个项目卡片，一次反序绑定后填写2段完整正文，名称和日期仍留空。重复不新增，反馈日志不含虚构个人值。测试预授予唯一保留来源和初始工具栏权限，不是浏览器权限弹窗或真实ATS验收。

实际测试结果请以当前提交产物为准。没有执行塔塔速度对照，没有宣称所有下拉/跨域/日历或真实达梦流程已经兼容。原目录未覆盖，用户仍需加载本次代码才能验证。
