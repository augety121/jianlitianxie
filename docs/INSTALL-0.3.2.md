# 0.3.2 安装、升级与核对

此包使用 MCP / Codex 与原本机资料主档；不包含完整独立加密资料工作台。版本：扩展/桥接0.3.2，通知协议2，页面引擎0.4.1。

## 已有用户

先保留原扩展安装路径、Codex配置和私有资料目录。不要卸载插件，不要清理浏览器存储，不要把 profile.json、evidence.json、bridge-token.txt、Cookie 或个人PDF复制进源码目录或GitHub。

将新源码包中的 **bridge 和 extension 一起更新**到原项目路径；bridge复用extension/core，不能只复制engine.js。保持 RESUME_DATA_DIR 指向原私有目录。配对码无需发给聊天或提交到仓库。

在Codex停用旧的resume_fill，确认旧的**该桥接**进程退出，再重新启动。不要结束无关Node进程。若提示旧版本占用端口，应退出旧桥接而不是反复连接；新桥接不会悄悄复用旧协议。

在 edge://extensions 或 chrome://extensions 对原扩展点击“重新加载”。回到具体岗位申请表，再点击工具栏图标；升级会尝试更新已授权网站的自动显示脚本，不申请新的网站权限。旧页面按钮未更新时从工具栏重新打开，必要时先确认网站是否已保存后再刷新。

## 首次安装

需要Node22+。源码无需npm运行时依赖；浏览器扩展是开发者加载包，不是商店签名安装。打开浏览器扩展管理的开发者模式，加载含 manifest.json 的 extension 文件夹，固定图标。在Codex按原README配置resume_fill，并用本机bridge-token.txt中的配对码配对。组织策略禁止安装时应由管理员处理，不绕过策略。

## 正常填写

进入具体申请表，先展开需要填写的分区；打开助手点击“扫描给Codex”。保持抽屉或已经配对的管理面板打开，然后切换到Codex组织计划；切换标签页本身不主动断开，但浏览器冻结/休眠仍可能断线。

检查本次计划和字段勾选，再授权填写。全选只选择可填写项目，已有值与手工项不强行填写。状态应区分待处理、填写中、停止中和已回读。只看到queued/delivered不是完成。

点击“停止填写”会请求执行器停止未完成项目，保留已经写入的值；等待回读结束再重新扫描。不会撤销网站自动保存的内容，也不会自动重试失败字段。

只保留一个选中的申请任务。另一个标签页不能读取、开始或取消当前计划；需要切换岗位时主动在新页面重新扫描。资料更新、5分钟超时、网页变化、取消或失败后，旧计划失效。主档修改后必须重新准备，而不是拿旧预览继续填。

## 异常处理

“连接中断”会退避重连通知，不会重试网页填写。收起助手或离开页面会取消等待；关闭瞬间到达的命令不会执行，重新打开后需要核对/重新扫描。

发生执行器或浏览器崩溃时，执行状态可能无法确认。先看网页实际值，不要连续点击填写；只有确认没有仍在运行的任务后，重启该resume_fill桥接并重新扫描。不要以删除主档、修改配对码、停止所有Node进程解决。

若结果提示“本地记录写入失败”，本次回读已结束，不能为补日志再次填写。检查私有资料目录权限，保留网页已有值。

## 验收边界

发布前仅有逻辑、合成DOM、模拟桥接的界面和本机传输基准测试；它们不等于已安装MV3、所有Chrome版本、真实招聘网站或塔塔全部功能通过。最低声明Chrome/Edge120并非逐版本实测承诺。

验证码、声明、附件服务器回执、复杂级联以及最终提交仍需本人核对。旧MCP资料为明文，输入网站后交给网站，授权给Codex的数据会进入其上下文。
