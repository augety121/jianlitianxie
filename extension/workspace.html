保护范围，请看清楚

本地模式没有资料上传或遥测；资料预览位于扩展自身页面，网页不能读取完整资料库或口令。填写时只把你勾选的字段值发送给目标文档。

加密存储不能防止已被攻陷的浏览器、操作系统、恶意本机程序或招聘网站读取已经填写的值。本机 MCP 仍使用受配对码保护的 loopback HTTP，不等于抵御具有本机高权限的攻击者。原 MCP 的历史明文文件不会被本次升级自动加密或删除。

本地工作台默认拒绝向外部 HTTP 页面填写。服务器端保存、提交、验证码和身份核验需要你核对。没有“所有网站零误填”或“绝对不会被截取”的承诺。
