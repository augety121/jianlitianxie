- 每个字段的日志提供规范名称、分区、控件类型、候选数量、对应方式、失败阶段和下一步；保留已有值不再被误说成核验通过。
- 合成测试与真实招聘网站分别记载，真实站点未验收的部分不宣称通过。

## 0.9.0：上传简历 → 核对解析 → 补填与纠错

- 支持文字型 PDF / DOCX 简历本地解析，编辑识别结果、所属经历，查看原文和未归类文字；保留 JSON / MD 导入和长短文。
- 识别普通 div 标签、重复项目卡片、明确标注的年月分离控件；整段经历可选“按简历顺序匹配空白经历”，先预览再填写。
- 网页已有值相同则跳过；不同值列出对照，逐项确认后加入填写计划。写入前再次检查旧值，写入后回读。
- **真实思谋页面验收尚未完成**：Edge 可列出登录标签页，但页面读取被浏览器权限核验拦截。合成 DOM 测试不是线上可用性保证。

[安装和操作说明](docs/UPGRADE-0.9.0.md)。无需重做 JSON；直接上传已有 PDF 简历即可开始核对。图片扫描件需先在本机转成文字；未知内容不自动编造。

## 0.8.5：按表单容量选正文，明确解释未填原因

- 同一项目资料可保存最多 5 份已核实的长短文。根据网页 `maxlength` 选择能完整容纳的最长版本，不生成、不截断、不混入其他项目。
- JSON 导入会逐份展示备选正文；增加或更新短版也计入待确认更新。资料编辑窗口可添加、修改和删除备选版本。
- 优先识别正式标签、ARIA 和标准 autocomplete；修复例子占位符盖过邮箱字段、共享行串用相邻标签的问题，补充有分区约束的英文项目/教育标签。
- 未填项区分正文超限、日期精度不足、数字框不接受面议、候选选项不匹配；已有网页值仍保留。
- 修复加密资料库方案保存/备份丢失和工作台缺失路由造成的 7 项基线测试失败。

安装、真实能力边界和本轮验证见 [0.8.5 操作说明](docs/UPGRADE-0.8.5.md)。个人资料请从本地文件导入，禁止放入仓库或扩展安装包。

## 0.8.4：先填已有资料，缺项不拦路

**点“填写简历” → 没有资料的留空 → 自己在网页补好 → 点“我补完了，记住内容” → 一次核对保存。** 不需要为每一个缺项返回资料管理页。已保存的补充内容下次可复用，默认仅用于当前网站。

本轮修复“企业名称”未作为已有经历锚点的问题；同段部门等字段可按明确唯一的公司资料匹配。补充读取不监听键盘、不自动保存、不覆盖旧资料；只在本人点击时读取本次扫描后填入的受支持空白项，并在扩展窗口核对后保存。免口令资料仍未加密，仅在本浏览器保存。详情与限制见 [0.8.4操作说明](docs/LEARN-LOCAL-0.8.4.md)。

**导入一次，在申请页直接点「填写简历」。** 本地保存、本地匹配，不要求 MCP、模型账号或配对服务。

## 从哪里填写？

进入真实招聘申请表，点击浏览器工具栏里的插件图标。右下角出现的绿色主按钮就是 **填写简历**：一次真实点击会扫描当前页面，再补全能够唯一确认的普通空白字段，每批最多60项。不必先扫描，不必跳转管理页，收起后的浮动按钮也可以直接执行。

已有内容不覆盖，密码、声明、附件、敏感项和不确定的资料不自动处理，最终保存/提交由本人完成。点击前请先核实插件中保存的个人资料。网站可能在输入时自动保存。

零个可填项时按钮不再消失或只剩“扫描”：原页展示具体待处理字段。点某一行的 **补填这项**，在扩展的小窗口选择正确资料、核对内容，再点 **确认填入这一项**。仅这个字段被填写，其他字段不动；不需要打开整页管理台。

## 导入和保存

首次点击“导入 / 核对修正”，上传 PDF / DOCX 简历或 MD / JSON / TXT 资料，看预览后确认保存。可使用 [MD 模板](extension/examples/local-profile.md) 或 [JSON 模板](extension/examples/local-profile.json)。JSON适合多段经历；MD支持明确字段、两列表格、分区和经历标题。未知段落不会被模型猜测为个人事实。

默认免口令资料保存在当前浏览器的 local 存储，**未加密、不使用 sync**。高级加密库独立保留，可输入旧口令一次预览后确认复制到免口令区，原加密资料不删除。不要把本地存储当成抵御已被控制的系统或浏览器的保证。

## 自动日志

默认记录本地导入、扫描、匹配、绑定、填写回读的状态、数值耗时、数量与匿名字段序号，不记录资料值、字段标签、URL、Cookie、口令或原始错误栈。可在“自动问题日志”预览后导出，不自动上传。缺日志不证明没有写入；失败不自动重填。

## MCP 可选

原加密库/MCP仍在高级入口。只有明确分享后，所选资料才进入本机桥接及 Codex 上下文。默认本地路径无需 Node 或桥接。旧明文主档仍是明文，loopback HTTP不是TLS；已交给网站或模型的资料不能撤回。

## 安装和升级

Chrome/Edge开发者模式加载包中的 `extension` 文件夹，不能选择仓库根目录。旧用户在原目录更新后重新加载，**不要先卸载或清空存储**；关闭旧的插件页面，在真实申请页重新点击工具栏图标即可。源码和扩展版本均以本次提交为准。MCP用户一起更新 bridge 与 extension，只重启对应 resume_fill 实例。

高级加密页的历史静态角标不代表共享引擎版本，以浏览器扩展详情为准。此前未同步的0.7.x候选模块不包含在这个发布路径；本版没有DOCX、独立命名简历或跨域全自动填写。
