# 简历填写助手 0.10.4

浏览器本地资料 → 扫描当前申请页 → 填写能够确认的普通空白项 → 独立回读。默认无需 Codex、MCP、配对码或资料库口令；不自动提交，不把没有资料的项目猜着填写。

## 这轮修复

0.10.4继续修复“只填写了语言，其他经历没有资料候选”的解析和匹配路径，而不是再增加一个扫描按钮。

- 识别“科研与项目经历”等标题、没有日期的编号项目、跨行括号标题、相邻分行的学校/日期和公司/日期。项目正文、明确职责和成果保留原句；发表年份不当作项目起止时间。
- 新增“检查并整理已存资料”。同一项目中已保存的项目背景、方案设计等明确片段可以整理成项目描述草稿，核对后保存；不删除原条目，不混合不同经历或网站范围。
- 显示已确认的教育、项目和工作/实习记录数量。保存条目总数不再是唯一状态提示。
- 家庭姓名/电话不使用本人资料，家庭同名字段也不再阻塞个人姓名；语言名称、熟练度、听说、读写分开匹配。获奖资料只有年份时只填年份，不补造月份。
- 日志保留实际引擎版本，区分未匹配、尚未尝试和写入后的回读失败；只导出固定规范字段、计数和原因，不导出个人值、原始标签或网址。

## 原目录升级

先备份，**不要卸载、清空浏览器存储或删除原vendor目录**。升级包内extension内容覆盖原extension目录，不要套成extension/extension；在扩展管理页重新加载，确认0.10.4。关闭旧工作台，再从真实申请页点击工具栏插件。不要为升级刷新未保存的申请表。

旧库只有零散项目片段时，点击“检查并整理已存资料”并核对保存。原文中的记录过去从未被解析保存时，升级不能凭空恢复它们，需要重新读取原文字型PDF/DOCX一次，或导入自己核对的facts JSON；旧资料保留，差异需核对。

回到申请页点击“填写简历”，普通空白项按已确认资料填写，缺项跳过。敏感项和已有值差异另行确认。保留500毫秒延迟回读，但回读不代表网站服务器已经保存或收到申请。

详情：[0.10.4升级说明](docs/UPGRADE-0.10.4.md)。前版的自定义下拉/表格导入修复见[0.10.3说明](docs/RECOGNITION-0.10.3.md)，日志导出与现有内容核对见[0.10.2说明](docs/UPGRADE-0.10.2.md)。

新增回归从虚构源文开始，经过实际解析器、记录对应和执行器，独立检查40个来源明确的字段实际值；无来源日期、亲属、健康、推荐码和语言等级必须保持空白。安装层从DOCX上传、确认保存、原页鼠标点击一直验证到回读与日志，不用脚本代替生产填写按钮。

这些是合成页面测试，不是登录态SmartMore、达梦或所有招聘网站验收。安装测试副本预授予仅本机虚构来源和工具栏来源标识，不验证实际授权弹窗。具体提交是否通过以GitHub Actions任务和原始JSON报告为准。历史性能对照本轮未重测，不宣称新的加速比例。

## 数据与安全

默认免口令资料保存在本浏览器，**未加密**，不使用云端解析或自动遥测。高级加密库和原MCP路径保留且分开授权；本地资料不会自动复制到MCP。填写给招聘网页的数据由该网站接收，网站可能自动保存。加密存储也不能抵御已被控制的操作系统/浏览器。

普通网页不能调用完整资料读取或修复预览。公开源码、测试和CI只使用虚构数据。真实简历、配对码、Cookie和私有导出不要上传GitHub。PDF/DOCX的本地依赖说明见[THIRD_PARTY.md](THIRD_PARTY.md)。
