# 简历填写助手 0.15.0

## 0.15.0：资料恢复、自动建段与回填

修复 Moka 姓名被必填错误文字干扰的识别；统一教育、工作、项目、语言、获奖记录。可在资料页选择本次经历；授权新增后，五域空表按选定资料顺序自动建段、填写和回读。已有歧义记录仍集中核对。

旧项目片段与语言资料可核对整理，保存后直接继续原申请页任务；已填页面可在空资料库中生成草稿，每张卡片只核对一次经历名称。保留原条目、来源和修改前版本，可恢复。日志 schema 4 区分写入成功、已有一致、已有未核实，以及宿主拒绝打开与打开未确认。

**真实 Moka 清空—回填—恢复尚未验收。** 安装版虚构 Moka 测试通过 18 段自动建段、65 项写入回读及再次运行零新增零写入。内置浏览器人工已能显示旧版面板，但工具仍无法操作封闭 Shadow DOM 和扩展协议页，也没有正式扩展重载接口。不能用隔离测试替代用户实机结论。详见 [0.15 实施与验收记录](docs/PROFILE-RECOVERY-0.15.0.md)。

本地优先：导入资料、核对保存，在申请网页点击 **填写简历**。普通模式无需 MCP、模型账号或资料库口令，不自动提交。

## 0.13.0：让已存资料真正进入填写流程

- 将“保存了多少条”与“有多少段可填写经历”分开显示。只有经历标识、没有标准字段的片段不再冒充可填写记录。
- 已存项目背景、方案等旧片段，可在申请网页直接点 **整理已存项目资料**。打开核对预览后再保存；保留原句、原条目、来源分区和网站限制，不推断项目名称、日期或缺少的教育经历。
- 没有 nav/aside 标记的侧边目录，与正文同名的教育/项目标题，不再直接导致所有新增分区冲突。只接受区域内唯一且有边界的新增入口；多个真实区域仍不擅自选择。
- “请输入”“请选择”等通用 ARIA 提示不再盖过同一字段旁明确的标签，不按视觉位置猜资料。
- 页内主按钮保留；记住补充、只读检查、导出日志和管理入口放入 **更多操作**。加密库和 MCP 仍在 **高级工具**，没有删除日志、备份或原功能。

## 使用

先备份，在原安装目录升级并重新加载，不卸载、不清空资料、不删除 vendor。页面助手与扩展详情应显示相同版本。

在申请页点主按钮。出现“整理已有资料并继续”时，核对后点“保存并继续填写”；首次新增点“按简历顺序添加经历并填写”。在资料页的“选择本次填写的经历”里决定使用哪些记录，不删除未选记录。详见 [升级与保留资料](docs/PROFILE-RECOVERY-0.15.0.md#升级与保留资料)。

缺少来源的字段保持空白。仅恢复已经保存的明确片段，不代表原文件所有内容都已找回。已有内容不擅自覆盖；附件与最终提交仍由本人操作。用户输入可能被招聘网站自动保存。

## 验证与开发

`npm ci --ignore-scripts` → `npm run build:engine` → `npm test` → `npm run check`。

新增 `npm run test:readiness` 和 `npm run test:readiness-mv3`。安装测试用临时浏览器、虚构资料和本地返回的保留域名页面；不是实际达梦账号或塔塔速度对照。新安装测试显式保留 Chromium 沙箱，Windows CI 必跑，原组件、本地、多记录、恢复和 MCP 流程保留。
