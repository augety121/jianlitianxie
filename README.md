# 简历填写助手 0.12.0

本地优先：导入资料、核对保存，在申请网页点击 **填写简历**。普通模式无需 MCP、模型账号或资料库口令，不自动提交。

## 0.12.0：组件策略层与执行诊断重构

运行引擎改为从 `src/autofill/` 的独立源模块确定性生成：页面会话、组件契约、选择动作分开维护。`extension/engine.js` 是可直接加载的打包结果，不需要用户自行构建；发布检查会拒绝源模块与打包结果不一致的版本。

本轮针对原扫描已经发现的输入控件，增加 Phoenix、Ant 新旧版本、Element、iView、React Select、ATSX 的显示值、点击入口和菜单策略。区分搜索输入与已选内容；再次扫描不能把已选专业重新当成空白。

执行日志新增固定阶段与是否已开始写入，区分打开/搜索/选择/回读；工作线程不再只保留一个笼统状态。日志仍不保存个人值、原始报错或网址。

这不是任意页面通用识别完成声明：没有新增扫描选择器，不适配没有输入/ARIA语义的任意div，未扩展跨域写入、闭合Shadow DOM或所有级联日历。已有记录保护、命中检查、显式授权及500毫秒回读保留。详见 [重构范围与验收](docs/COMPONENT-REFACTOR-0.12.0.md)。

## 使用

已有用户先备份，在原安装目录升级并重新加载，不卸载、不清空资料、不删除 vendor。原页面助手与扩展详情应显示相同版本。

原有多行MD、JSON、PDF/DOCX导入、独立命名简历、站点授权、零卡片新增、一次经历对应及补充内容保存继续保留。读取原文件后检查教育/实习/项目数量，不以“保存若干条”代替完整性核对。

## 开发

`npm ci --ignore-scripts` → `npm run build:engine` → `npm test` → `npm run check`。

新增组件浏览器测试：`npm run test:components`。安装回归沿用原本地、记录确认、恢复与MCP流程；实际结果以当前提交CI为准，不引用旧提交的绿色状态。
