# 简历填写助手 0.11.1

本地优先的浏览器扩展：导入简历、核对保存，在申请网页点击 **填写简历**。默认不需要 MCP、模型账号或资料库口令；不自动提交。

## 本次修复

- Markdown 的 `**字段名**` 加下一段正文可以完整导入；保留分段项目正文，冒号不再拆散正文。
- 识别零卡片的教育、实习和项目区，以及纯 div 标题旁的“＋添加”。只创建有已核实来源、结构明确的记录，不动附件和家属区。
- 新增未获允许时，先填普通字段，原页显示 **允许添加经历并继续填写**。此动作只允许当前站的新增，不自动授予常驻或其他网站访问权限。
- 姓名旁的结构化校验提示不再混入字段名；填写后报错提示消失也不再误判为字段改名。
- 每次填写记录无值新增诊断，区分未允许、缺少来源记录、没有新增按钮、结构不明确、已足够和实际新增。

## 第一次使用

1. 在浏览器加载 `extension` 文件夹。已有用户在原安装目录升级并重新加载，不要先卸载或清空存储。
2. 到申请页点击工具栏插件图标，导入原来的 MD、JSON、PDF 或 DOCX，检查解析结果后保存。
3. 在网页点击 **填写简历**。需要新增时，点击原页的新增允许按钮；有歧义的经历只做一次整体对应。

旧版本已经漏掉的资料不能凭空恢复。使用新导入器重新读取原文件一次，核对教育/实习/项目数量；重复条目去重，变化内容须确认，原库不会自动删除。多份命名简历和原加密库/MCP入口继续保留。

## 验证与边界

已安装验证与浏览器结构测试使用虚构资料、临时浏览器和离线测试页面，不是实际达梦登录页验收，也不是塔塔速度对照。未适配的级联、跨域子页面和复杂新增结构会跳过，不猜个人资料，不自动保存或提交。真实页面可能在输入时自行保存数据。

免口令模式是浏览器本机未加密存储，不使用 sync 或云端解析。日志不含资料值和原始网址；本机被控制或网站收到已填内容不在静态存储保护范围内。

开发检查：`npm ci --ignore-scripts`、`npm test`、`npm run check`。新零卡片测试：`npm run test:empty-records` 和 `npm run test:empty-mv3`；浏览器依赖见 `requirements-test.txt`。
