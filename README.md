## 开发验证

先 `npm ci --ignore-scripts`，然后运行 `npm test` 和 `npm run check`。浏览器测试使用 `requirements-test.txt` 的 Playwright 与完整 Chromium，所有数据为虚构。

新增安装链路测试：`python tests/refactor-mv3.py`。它使用临时浏览器和虚构本机表单，预先授予测试来源和初始工具栏授权；不等于真实权限弹窗、用户实际浏览器或达梦官网验收。

免口令资料在浏览器本地未加密保存，不使用 sync，不默认调用 MCP/云端模型。网站仍会收到本人主动填写的值。旧明文主档、此前备份和已发送内容不会自动清除；生产升级前必须单独验证资料可恢复。
